# AlcoKa 3.4

Новый автономный релиз калькулятора разбавления спирта водой для Windows.

## Изменения

- Проект и приложение обновлены до версии 3.4.
- Добавлено сохранение языка, единиц измерения, размеров окна и последних значений.
- Добавлена история последних расчётов.
- Результаты можно копировать в буфер обмена и экспортировать в TXT.
- Усилена проверка ввода: диапазон крепости 0-100%, обработка нулевых объёмов и нечисловых значений.
- Расчёты переведены на `Decimal` для более предсказуемого округления.
- Сохранена поддержка русского, английского и немецкого языков.
- `whiskey.ico` встроен как значок приложения и трея.
- `dollar.ico` встроен как значок окна.
- Сборка распространяется одним автономным файлом `AlcoKa.exe`.

## Установка

Скачайте `AlcoKa.exe` из assets этого релиза и запустите. Python и отдельная установка зависимостей не требуются.

Регрессионные тесты: `5 passed`.
