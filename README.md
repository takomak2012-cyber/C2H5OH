🧪 Калькулятор разбавления спирта (C2H5OH Dilution Calculator) — multilingual.exe

Простая и удобная программа-калькулятор для расчёта разбавления спирта (этанола) водой. 
Имеет интуитивно понятный графический интерфейс на базе tkinter и работает под Windows.

✅ Три режима расчёта:
- Вода — сколько воды добавить к известному объёму спирта
- Объём — сколько спирта и воды взять для заданного готового объёма
- Итог спирта — какая крепость получится после смешивания

✅ Поддержка единиц измерения:
- Спирт: %, г/л, мг/л, ppm, усл. ед.
- Объём: мл, л, мкл, капли

✅ Мультиязычный интерфейс:
- Русский
- English
- Deutsch

✅ Переносимость:
- Один исполняемый файл .exe (multilingual.exe)
- Не требует установки Python или дополнительных библиотек
- Все иконки вшиты в файл, переносится на любой ПК
