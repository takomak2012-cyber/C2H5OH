# AlcoKa 3.4

Калькулятор разбавления спирта водой для Windows. Программа распространяется одним автономным файлом `AlcoKa.exe` и не требует установки Python.

[Скачать AlcoKa 3.4](https://github.com/takomak2012-cyber/C2H5OH/releases/tag/v3.4) | [Исходный код](https://github.com/takomak2012-cyber/C2H5OH/blob/main/dilution_calculator.py) | [История изменений](RELEASE_NOTES_v3.4.md)

## Возможности

- Расчёт количества воды для разбавления известного объёма спирта.
- Расчёт объёма спирта и воды для заданного готового объёма.
- Расчёт итоговой крепости после добавления воды.
- Поддержка русского, английского и немецкого языков.
- Единицы крепости: `%`, `г/л`, `мг/л`, `ppm`, условные единицы.
- Единицы объёма: `мл`, `л`, `мкл`, капли.
- Проверка диапазона крепости и некорректных числовых значений.
- Точные расчёты через `Decimal` и округление до сотых.
- Запуск расчёта клавишей `Enter`.
- История расчётов и сохранение последних настроек.
- Копирование результата и экспорт в TXT.
- Значок приложения и трея `whiskey.ico`.
- Значок окна `dollar.ico`.

## Расчётная формула

`Начальная крепость × объём спирта = целевая крепость × итоговый объём`

Пример: для 500 мл спирта крепостью 96% и цели 40% итоговый объём составляет 1200 мл, поэтому нужно добавить 700 мл воды.
